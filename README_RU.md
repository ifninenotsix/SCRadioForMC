# SoundCloud Radio

[English version](README.md)

Мод для Minecraft Forge 1.19.2, который добавляет предмет **Radio**. Правый
клик по нему открывает плеер: вставь ссылку на трек или плейлист SoundCloud —
музыку слышат игроки рядом. Громкость падает с расстоянием, а стерео-панорама
зависит от того, где стоит держатель радио.

Внешний плеер не нужен: декодеры AAC и MP3 упакованы прямо в JAR мода.

## Возможности

- Воспроизведение публичных треков и плейлистов SoundCloud прямо из игры.
- Прокручиваемый список треков с поиском по названию или номеру; клик по строке
  переключает трек. Текущий трек подсвечивается.
- Поддержка больших плейлистов. Проверен плейлист на **482 трека**: мод запрашивает
  полный список, а не останавливается на коротком превью, которое иногда возвращает
  SoundCloud.
- Позиционный звук: затухание по расстоянию и панорама относительно держателя радио.
- Громкость и бассбуст задаёт держатель радио — все слушатели рядом слышат один и тот
  же микс. Свои значения конфига у слушателей при этом не перезаписываются.
- Трёхполосный эквалайзер (низ / середина / верх) работает локально у каждого игрока.
- DSP полностью на Java: бассбуст и эквалайзер применяются к PCM до вывода звука,
  поэтому не нужны нативные регуляторы звуковой карты.
- Сервер не скачивает аудио и не получает подписанные CDN-ссылки. Каждый клиент сам
  резолвит и декодирует свой поток.

## Требования

- Minecraft **1.19.2**
- Forge **43.x** (`forge_version_range = [43,)` в этом проекте)
- Java **17** для сборки и запуска
- Интернет на клиенте для запросов к SoundCloud

Gradle Wrapper скачает Gradle сам — локально ставить Gradle не обязательно.

## Установка

1. Установи Forge 43.x для Minecraft 1.19.2.
2. Скачай JAR из Release или собери его сам (см. ниже).
3. Положи **`soundcloudradio-1.19.2-1.0.0-all.jar`** в папку `mods`.
   Нужен именно `-all.jar`: обычный JAR не содержит декодеры AAC/MP3.
4. Для мультиплеера поставь тот же JAR на сервер. Сервер использует мод, чтобы
   рассылать состояние воспроизведения и проверять, что игрок всё ещё держит радио.
   В одиночке интегрированный сервер загружает мод автоматически.

> Клиенты и сервер должны использовать одну версию JAR. Сейчас версия сетевого
> протокола — `2`.

## Сборка

Windows:

```powershell
.\gradlew.bat build
```

Linux / macOS:

```bash
./gradlew build
```

Результат:

```text
build/libs/soundcloudradio-1.19.2-1.0.0-all.jar
```

Для разработки:

```powershell
.\gradlew.bat runClient
.\gradlew.bat runServer
```

Сборка проверена на JDK 17 и Gradle 8.1.1. Реальное воспроизведение AAC-HLS
проверено на 44.1 kHz / 16 bit / stereo.

## Использование

1. Достань радио:
   - креативный таб **Misc**, или
   - `/give @p soundcloudradio:radio`
2. Правый клик по радио открывает плеер.
3. В GUI уже вставлен плейлист по умолчанию из конфига. Замени его на любую
   публичную ссылку SoundCloud и нажми **Load**.
4. Работа со списком треков:
   - впиши в **Search tracks** название или номер для фильтра;
   - клик по треку запускает его;
   - текущий трек подсвечивается.
5. Кнопки: **Play/Pause**, **Stop**, **Prev**, **Next**. Треки переключаются
   сами, если включён `autoNext`.
6. Ползунки:
   - **Volume** и **Bass boost** слышат все слушатели твоего радио;
   - **EQ Low / Mid / High** влияют только на твой вывод звука.

Все значения ползунков сохраняются при закрытии окна.

## Конфиг

Файл `config/soundcloudradio-client.toml` создаётся после первого запуска.

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `playlistUrl` | встроенный демо-плейлист | ссылка, которая подставляется в GUI |
| `clientId` | `""` | свой SoundCloud `client_id`; пусто = поиск на сайте |
| `volume` | `80` | громкость радио, `0..100` (%) |
| `bassBoost` | `0` | бассбуст, `0..100` (`0` = выкл., `100` ≈ +15 dB на 100 Гц) |
| `eqLow` | `0` | низ, полка 250 Гц, `-12..+12` dB |
| `eqMid` | `0` | середина, пик 1 кГц, `-12..+12` dB |
| `eqHigh` | `0` | верх, полка 4 кГц, `-12..+12` dB |
| `radius` | `48.0` | радиус слышимости в блоках вокруг держателя радио |
| `autoNext` | `true` | автоматически включать следующий трек после окончания текущего |

Если автоматический поиск `client_id` сломается после изменений на сайте
SoundCloud, впиши актуальный `client_id` вручную в `clientId`.

## Как это работает

- `api-v2.soundcloud.com/resolve` превращает ссылку на страницу в трек или плейлист.
  Для плейлистов мод дополнительно запрашивает `/playlists/{id}`, чтобы получить
  полный список. Треки, которые SoundCloud отдаёт только как заглушки
  `{ id, kind, policy }`, догружаются через `/tracks/{id}` в небольшом пуле потоков.
  Поэтому работают плейлисты на 150+ треков. Первая загрузка очень большого
  плейлиста может занять несколько секунд.
- `client_id` ищется в JS-бандлах SoundCloud и кэшируется на 12 часов.
- SoundCloud чаще всего отдаёт AAC-HLS / fMP4; используются JAAD и небольшой
  demuxer `moof/trun/mdat`. Для прогрессивных MP3-потоков есть mp3spi/JLayer/Tritonus.
- Звук приводится к `44100 Hz / 16-bit / stereo / little-endian` PCM. Бассбуст и
  эквалайзер — биквадные фильтры RBJ, применяются на Java прямо перед записью
  сэмплов в `SourceDataLine`.
- Сервер получает только URL страницы SoundCloud, название, номер трека,
  id игрока/сущности, громкость и бассбуст держателя — но никогда CDN-ссылку на аудио.
- Позиционный звук сделан через Java Sound `MASTER_GAIN` и `PAN`. Это не нативный
  звуковой движок Minecraft: нет экранирования стенами и эха.

## Ограничения

- Работают только публичные треки. Приватные, регионально заблокированные и
  удалённые треки не дадут поток.
- Поддерживаемые кодеки: AAC-HLS и MP3. Opus/FLAC не поддерживаются.
- Мод использует внутренний API SoundCloud (`api-v2`), а не официальный публичный.
  Изменения на сайте могут временно сломать резолвинг.
- Ответственность за проигрываемый контент лежит на игроке.
- Проект не связан с SoundCloud и не одобрен им.

## Устранение проблем

| Симптом | Что проверить |
|---|---|
| Звука нет вообще | Громкость, расстояние/`radius`, доступ клиента к SoundCloud |
| Загрузилось всего несколько треков | Используй свежий `-all.jar`; старые JAR останавливались на превью API |
| `Could not find a SoundCloud client_id` | Укажи `clientId` вручную в конфиге |
| Краш с `junit.awtui` или module resolution | Ты используешь старый JAR; текущие сборки исключают JUnit/Hamcrest |
| В мультиплеере ничего не происходит | Мод должен быть и на сервере, с той же версией протокола |
| Большой плейлист долго появляется | Это нормально: во время Load догружаются метаданные треков-заглушек |
